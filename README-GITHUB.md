# Local Run Rozzie PWA

Upload all contents of dist/ to your GitHub Pages publishing folder (repository root or docs/), keeping index.html, pwa.js, sw.js, manifest.webmanifest, icons, PDF and assets together. Enable GitHub Pages with HTTPS. Do not upload just index.html: installation and offline support require the companion files. Relative paths support a GitHub project subdirectory. .nojekyll avoids Jekyll processing.

Current QR destination: https://local-run-rozzie.seymoregreen.chatgpt.site (the existing public platform). If you move exclusively to GitHub Pages, regenerate the PDF QR with your final Pages URL before printing.

Android Chrome: menu > Install app / Add to Home screen. iPhone Safari: Share > Add to Home Screen > Open as Web App. Desktop Chrome/Edge: use install option where supported. First visit requires HTTPS and internet. Offline presentation is cached after first successful visit. External map, email signup and outside links require internet. Install availability depends on browser and device.

This is a presentation and email-based interest signup PWA. No live orders, backend accounts, payments, runner verification, tracking or dispatch have been connected. Final fees and operating terms need configuration before accepting deliveries.
